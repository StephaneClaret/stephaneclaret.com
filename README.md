# stephaneclaret.com

Page professionnelle de Stéphane Claret, servie par GitHub Pages depuis ce dépôt.

- Une page statique en français (`index.html`) et sa version anglaise (`en/index.html`), une feuille de style (`assets/site.css`).
- Aucune ressource externe : police Work Sans auto-hébergée (`assets/fonts/`, licence OFL dans `NOTICE.md`), aucun script exécuté (seul un bloc JSON-LD de données structurées), pas de police ni d'image tierce, pas de mesure d'audience.
- La photo est servie en WebP à deux tailles, sans métadonnées ; `assets/og.jpg` sert aux aperçus de liens. `assets/ines-mark.png` est le logo d'Inès.
- Lisible par les moteurs et les agents d'IA : JSON-LD schema.org `Person` dans chaque page, `robots.txt`, `sitemap.xml`, `llms.txt`.
- `CNAME` porte le domaine ; `.nojekyll` demande à Pages de servir les fichiers tels quels.
